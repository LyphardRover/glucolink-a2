# evidence

Screenshots that show both the query and its result.

## Rules (Task Cards v3, card F-2)

1. **File name:** `YYYY-MM-DD_<package letter>_<what>.png`, for example `2026-10-01_C_source_counts.png`.
2. **Content:** each screenshot shows the **query**, the **result grid** and the **database name**
   (the CloudBeaver connection or database shown in the header). A result without the query is not evidence.
3. **One screenshot per acceptance check**, uploaded by the owner of that card from their own GitHub account,
   then posted in Teams with the file name (decision D10: "done" = file in GitHub + run on the shared DB + check passes + screenshot in Teams).
4. The full list of expected screenshots, with due times and owners, is the sheet **Evidence checklist**
   in `tests/test_plan_v1.xlsx`. Minha (F) updates it daily and reminds owners in Teams.
